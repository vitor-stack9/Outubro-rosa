# Outubro Rosa

Página web desenvolvida em HTML e CSS com informações e conscientização sobre o Outubro Rosa.

## Tecnologias utilizadas
* HTML5
* CSS3

## Estrutura do projeto
* `1.HTML` - Estrutura principal da página
* `Estilos/1.CSS` - Arquivo de estilização
* `Imagens/` - Pasta com as imagens utilizadas
